## 完整游戏流程

```
封面
  ↓ 点"走进回响"
问卷（5题）
  ↓ 提交
介绍页（性格类型 + 标签）
  ↓ 点"开始这三天"
世界场景 ← ← ← ← ← ← ← ← ←（对话结束后返回这里）
  ↓ 走到 NPC 旁按 E
对话系统
  ↓ 选选项
内心独白 + 教育回响
  ↓ 等待 / 自动推进
下一场景
  ↓ （6个场景都完成后）
终局（性格总结）
```

---

## 操作说明

| 按键 | 动作 |
|------|------|
| WASD / 方向键 | 移动 |
| 空格 / E | 与 NPC 互动（靠近时） |
| 鼠标左键 / 空格 | 跳过打字机效果 / 推进对话 |
| 鼠标 | 点击选项按钮 |
