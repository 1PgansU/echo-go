# 封面视频素材

把视频文件放在本目录下，命名 **cover.mp4**（或 cover.ogv / cover.webm）：

- `cover.mp4`  （推荐，H.264 + AAC）
- `cover.ogv`
- `cover.webm`

> Godot 4 在浏览器 / 桌面端均支持 mp4 视频纹理作为 VideoStream。

## 主题建议

可选主题（与游戏"教育回响"主题契合）：

1. **教室 / 黑板** —— 阳光透过窗户，光斑在课桌上移动
2. **走廊 / 校道** —— 学生匆匆走过，落叶飘飞
3. **家中客厅** —— 暖色调，老照片挂在墙上，窗外黄昏
4. **黄昏校园** —— 操场，单车，秋千
5. **逆光少年背影** —— 站在教学楼天台，看城市

推荐网站下载（**免费可商用 CC0 / Public Domain**）：

- [pixabay.com/videos](https://pixabay.com/videos/) — 搜索 `school classroom sunset` `student hallway`
- [pexels.com/videos](https://www.pexels.com/videos/) — 搜索 `high school` `childhood memories`
- [coverr.co](https://coverr.co/) — 适合氛围类视频

下载后改名为 `cover.mp4` 放在此目录即可。
